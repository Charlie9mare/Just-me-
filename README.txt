Residential Application Website

index.html  = the whole website (home, apply form, admin) in one file.

Edit it in any text editor to change the company name ("Your Property Co.") and logo.

Note: saving applications and the admin dashboard only work when the page is
published from Claude. Opened on its own, the form shows that saving is not available.
For a public site with its own server, use residential-app.zip instead.
